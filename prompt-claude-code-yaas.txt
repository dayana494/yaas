ПРОМТ ДЛЯ CLAUDE CODE: САЙТ-ВИЗИТКА ЭНЕРГЕТИКА YAAS
====================================================

Собери сайт-визитку энергетика на React + Three.js (react-three-fiber + drei). Сайт состоит из двух «экранов» (секций), между которыми происходит анимированный переход через 3D-сцену с банкой напитка.

ТЕХНОЛОГИИ
----------
- React (Vite)
- three, @react-three/fiber, @react-three/drei
- gsap для тайминга анимаций, синхронизированных с 3D-объектом
- Модель банки: 18.08.2026.glb (используй draco/meshopt-компрессию через useGLTF, если применимо)
- Этикетки (развёртки, папка "этикетки/"): lemon.jpg, orange.jpg, apple.jpg, strawberry.jpg, blueberry.jpg — применяются как текстура на UV-развёртку банки, меняются через THREE.TextureLoader
- Референсы стилистики: "референсы/референс стилистики.png", "референс стилистики 2.png" (общий вайб/цвет/композиция — заимствовать настроение, не копировать элементы), "референс второго экрана.jpg" (только структура блоков — заголовок сверху слева, банка справа снизу, переключатель вкусов слева снизу)

ПРОИЗВОДИТЕЛЬНОСТЬ (важно!)
----------------------------
- Лёгкий, оптимизированный код без лишних зависимостей.
- Ленивая загрузка (React.lazy + Suspense) для второго экрана.
- 3D-сцена подгружается прогрессивно после отрисовки UI-каркаса (не блокирует первый рендер).
- Текстуры этикеток — компрессированные, предзагружаются заранее через useTexture (массив путей), чтобы не было "мигания" при первой смене вкуса.
- Мемоизация материалов/геометрии (useMemo), никаких пересозданий на каждый ререндер.
- Минимум дорогих эффектов (тени, постпроцессинг) — только там, где критично для визуала.
- Цель — быстрый LCP, сцена не должна тормозить загрузку страницы.

СТИЛИСТИКА
----------
- Шрифт: Soledago (подключить как @font-face, локальные файлы, с системным sans-serif фолбэком на время загрузки).
- Логотип — не отдельный файл, а текст "YAAS" шрифтом Soledago.
- Динамический фон, привязанный к активному вкусу, с плавным градиентным crossfade между цветами при переключении:
  - Lemon → #F3D118
  - Apple (Green Apple) → #189C65
  - Strawberry → #E53A6B
  - Blueberry → #0085C6
  - Orange → #F08221
- На фон можно добавить лёгкую органическую текстуру/узор (волны, крапинки, пятна), но с низкой прозрачностью (~5–10%), чтобы не спорить с банкой и текстом — они всегда в фокусе.
- Общий стиль: современный, дорогой, молодёжный. Крупная выразительная типографика, чистые формы, плавные переходы, без визуального шума.

ТЕКСТЫ (сгенерируй сам по смыслу, в стиле бренда энергетика Yaas)
------------------------------------------------------------------
Для каждого из 5 вкусов подготовь:
- Заголовок — название вкуса на английском в стиле "Green Apple", "Wild Strawberry", "Blue Berry Rush", "Citrus Lemon", "Solar Orange" (подбери звучные варианты).
- Описание — короткое, ровно 2 предложения, в духе энергетика (динамика, вкус, ощущение бодрости), без клише про "депрессию" и т.п. — держи в тоне премиального молодёжного бренда.

ОБЩАЯ СТРУКТУРА
----------------
- Один общий <Canvas> на весь сайт (сцена не пересоздаётся между экранами — банка "переезжает" плавно между состояниями).
- HTML-UI слоями через обычные React-компоненты с абсолютным позиционированием поверх Canvas.
- Стейт-машина верхнего уровня: screen: 'slider' | 'detail', activeFlavor: number (0–4), состояние банки (позиция/поворот/масштаб), управляемая gsap-таймлайнами.

ЭКРАН 1 — СЛАЙДЕР ВКУСОВ
-------------------------
Механика (референс — первый экран ciaoenergy.com, структуру заимствуем, не стили):

1. Логотип-текст "YAAS" сверху по центру.
2. Слайдер из 5 банок в ряд по дуге (крайние развёрнуты сильнее, центр — прямо).
3. Управление: стрелки влево/вправо + drag/swipe мышкой с инерцией и snap к ближайшей банке.
4. При смене активного вкуса:
   - Банки плавно сдвигаются по дуге (tween позиции + поворота).
   - Название вкуса под центральной банкой сменяется fade/slide.
   - Фон плавно crossfade-ится в цвет нового активного вкуса.
5. Центральная банка:
   - Ярче освещена (отдельный spotLight/повышенная интенсивность), остальные — затемнены.
   - Лёгкий parallax-поворот по позиции курсора (lerp, без резких скачков).
6. Клик по центральной банке → переход на экран 2:
   - Банка (gsap timeline) опускается вниз, перемещается в правый нижний угол, поворачивается на 45° влево (смотрит в левый верхний угол).
   - Остальные 4 банки и UI слайдера уходят/фейдятся.

ЭКРАН 2 — ДЕТАЛЬНАЯ КАРТОЧКА ВКУСА
------------------------------------
Структура (референс — только раскладка блоков из "референс второго экрана.jpg"):

- Левый верхний угол: заголовок вкуса + описание (2 предложения), fade/slide-in после того, как банка встала в финальную позицию.
- Правый нижний угол: 3D-банка в позе 45°, с тем же лёгким pointer-parallax.
- Левый нижний угол: переключатель вкусов (5 пунктов, активный выделен).

Смена вкуса на экране 2:
- Клик по вкусу запускает поворот банки на 360° (начало и конец в той же позе 45°).
- На ~180° поворота (когда банка развёрнута тыльной стороной) подменяется текстура этикетки.
- Заголовок и описание сменяются fade out/in, синхронно с серединой поворота банки.
- Фон плавно crossfade-ится в цвет нового вкуса.

МОБИЛЬНАЯ АДАПТАЦИЯ
---------------------
- На мобильных: одна банка по центру видимой дуги вместо пяти (экран 1), сохраняется механика клика → переход.
- На экране 2: банка опускается в низ по центру экрана (занимает ~50% высоты экрана), заголовок и описание — над банкой, переключатель вкусов — под ней или в нижней части (адаптируй расположение компактно).

НЕ НУЖНО РЕАЛИЗОВЫВАТЬ СЕЙЧАС
-------------------------------
- Fallback для браузеров без WebGL.
- Звук/переключатель звука.
- Кнопки Contact/Menu и любую доп. навигацию.

ПОРЯДОК РЕАЛИЗАЦИИ
--------------------
1. Базовая структура проекта + статичная раскладка обоих экранов с банкой без анимаций.
2. Карусель на экране 1 + pointer-parallax + затемнение боковых банок.
3. Переход банки между экранами (клик → gsap-анимация позиции/поворота).
4. Поворот на 360° + смена этикетки/текста на экране 2.
5. Динамический фон с crossfade по палитре вкусов.
6. Подключение шрифта Soledago, финальная типографика и тексты.
7. Оптимизация: lazy-loading, мемоизация, сжатие ассетов, проверка производительности.
